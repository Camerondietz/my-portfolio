HR Analytics & Predictive Modeling

EDA and Random Forest model (AUC 0.96) on a 15K-row HR dataset to identify turnover drivers.

Pythonscikit-learnPandasEDA

Analyzed a 14,999-row HR dataset to uncover insights into employee retention and build predictive models for identifying key turnover factors. Removed 3,008 duplicates, flagged 824 tenure outliers with IQR, and validated data types and missing values during preprocessing.

Key Analysis Steps

  • Retention analysis: 16.6% of employees had left. Boxplots, histograms, and scatter plots highlighted that higher workloads increased turnover.
  • Tenure & salary insights: Lower satisfaction (mean 0.44) for those who left vs. 0.67 for retained employees. Higher turnover among short-tenured, low-salary employees.
  • Department trends: Counts revealed varied retention rates, indicating need for department-specific strategies.

Predictive Modeling

  • Logistic Regression: 82% accuracy, macro F1 0.61.
  • Decision Tree (GridSearchCV tuned): AUC 0.9587, precision 0.857, recall 0.904.
  • Random Forest: AUC 0.9648 — top features were satisfaction level, average monthly hours, and tenure.

Results underscore the importance of job satisfaction, workload, and tenure in predicting employee departure — offering a data-driven approach to HR management.

Topographical Pathfinder — C++

Reads elevation data, renders a grayscale PPM map, and overlays the least-elevation-change path.

C++AlgorithmsImage Processing

C++ program that maps the most efficient route through terrain using topographical map data. Reads elevation values, processes them into a grayscale PPM image, and highlights the optimal path.

Input handling: Prompts for rows, columns, and the input file; validates and opens the file for reading.

Data processing: Stores elevations in a 2D vector and computes min/max for grayscale scaling.

Grayscale mapping: Maps each elevation to a 0–255 intensity stored in RGB vectors.

Path coloring: A colorPath function determines the least-elevation-change path and overlays it; the shortest is rendered in bright green.

Output: Writes a PPM file with grayscale terrain and colored overlay paths.
